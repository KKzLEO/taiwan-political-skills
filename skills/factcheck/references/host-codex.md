# 在 Codex 上派出角色

流程和指令見 SKILL.md 的第 2–8 步。第 2 步的讀入與拆題和主模型的席位都跑 `codex exec`：在空的暫存資料夾裡執行，只拿到該角色的指令和輸入資料，看不到這段對話。

**隔離程度：** 2026-11-18 的金絲雀實測顯示，子程序一定會讀到使用者的 `~/.codex/AGENTS.md`，`--ignore-user-config` 只會跳過 config.toml。要完整隔離，用 `FC_CODEX_CMD` 指向另一個乾淨、自己登入過的 Codex 設定。

**逾時：** 每個子程序可能要跑好幾分鐘，`claude -p` 當外部反方時可能超過 10 分鐘。`run-model` 的逾時上限預設 3600 秒，可以用環境變數 `FC_TIMEOUT` 調整；你自己執行指令時，工具的 timeout 也要設得比它長。
