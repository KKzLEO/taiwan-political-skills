# 分數怎麼算

這份文件和 `scripts/fclib/score.py` 必須一起改。分數完全由腳本計算，模型不能調整。

## 可信度（0–100）

```
可信度 = 100 × 命題正確度
```

**命題正確度：** 計分命題（排除 `not_factual`）的係數，依重要性加權平均。

| 判定 | 係數 |
|---|---:|
| 正確 | 1.00 |
| 大致正確 | 0.80 |
| 部分錯誤 | 0.50 |
| 無法證實 | 0.35 |
| 誤導 | 0.25 |
| 錯誤 | 0.00 |

四捨五入到整數（.5 進位）。

**證據品質不算進可信度。** 證據品質講的是「我們查得多扎實」，所以放在信心度裡。如果放進可信度，反駁得越扎實，一則假訊息的分數反而越高。第一版就是這樣設計的，結果十則全假的訊息拿到 40 分、被判成「部分符合」，見 CHANGELOG 0.1.0。

**脈絡問題不另外扣分。** 斷章取義、舊圖新用這類問題已經反映在「誤導」等判定上；如果再扣一次，等於重複處罰。脈絡問題仍然會列在報告裡。

## 查核結果

依序套用第一個符合的條件：

1. 沒有計分命題 → 無法判定
2. 「無法證實」的重要性權重 ≥ 50% → 無法判定（查不到不等於假的）
3. ≥ 80 符合；60–79 大致符合；40–59 部分符合；< 40 不符

## 查核信心度（0–100）

從 100 開始扣，最低 0：

| 情況 | 扣分 |
|---|---|
| 證據品質不滿分（見下方） | −20 × (1 − 證據品質)，四捨五入 |
| 沒有任何執行成功的跨模型席位 | −20 |
| 有跨模型席位，但都不能上網 | −10 |
| 每個覆核沒通過的命題 | −10 |
| 核心命題的直接證據全都存取受限（沒有任何一筆 `access_note` 是 `full`） | 每個命題 −10，最多 −30 |
| 有法條命題沒有取得條文原文 | −15（一次） |
| 快速模式 | 上限 60 |

**證據品質（0–1）：** 只看核心命題（沒有核心命題就看全部計分命題），依重要性加權平均。每個命題：
- 直接證據（`supports` 或 `refutes`）裡有第一層或第二層來源：+0.5
- 直接證據來自兩條以上不同的 `chain`：+0.5

高 ≥ 75、中 50–74、低 < 50。

**可公開：** 完整模式、信心度高、至少一個跨模型席位成功。

## 不影響可信度的指標

媒體立場、信任度、記者署名、報導用詞、操弄手法都只顯示在報告裡，不算進分數。看是哪家媒體就先打折，正是這個工具要避免的偏見。
