# 實際執行的範例

每個資料夾都是一次完整查核的所有紀錄，任何人都可以檢查報告是怎麼得出來的。這些報告也可以直接在網站上看（台北市長選舉的議題，要兩位候選人的那一則都跑完才會出現）：<https://kkzleo.github.io/taiwan-political-skills/reports/>

```bash
python3 skills/factcheck/scripts/fc.py status --run examples/<資料夾>
```

把資料夾複製出來（名稱不要改）執行 `fc.py render --run <複本>`，會得到一模一樣的 `report.md`。
