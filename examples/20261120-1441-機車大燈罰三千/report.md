## 已檢驗的質疑

- （C1）「內容與騎機車開大燈有關」把原訊息擴大成任何涉及機車頭燈的法案，連燈具設備或特定道路管制的修法也可能算進去。建議改成「立法院三讀通過一項要求騎機車一律開大燈的法案」。原文「昨天」所指的日期已由 C5 查核。 → 不成立：這一條查的是「有沒有這次三讀」，「一律要開」的內容由另一條查；把「一律」寫進來，兩條會重疊。現行寫法比原文寬，對訊息較有利，沒有加重原文的說法。即使照較寬的範圍查，立法院第11屆第6會期第7次、第8次院會的議程都沒有機車頭燈的項目，道路交通管理處罰條例最近一次三讀（115年7月28日）改的也不是燈光條文，改不改寫都不影響判定。
- （C4）原文寫「以後」，沒有交代哪一天開始適用。C4 加入「已經生效，現在就適用」，把可能的讀者解讀寫成原訊息的主張。建議刪除這條隱含命題，由 C2 查核原文所稱將來一律開燈的義務。 → 不成立：改寫比原文強這一點是對的，已經修正成「三讀通過之後就開始適用」；但刪掉整條沒有必要。三讀、公布、施行是不同階段。訊息寫「三讀通過，以後一律要、沒開罰三千，快轉給家人」，沒有交代施行日期，會讓讀者以為三讀後就適用，適用時點需要單獨查核。
- （溯源）兩則 Cofacts 紀錄的繁體中文版可讀到回報內容、首次回報的相對時間、標籤及查核回應。溯源可以補上這些資料，並註明它們是相近訊息的回報紀錄，無法用來確定本次訊息的首發時間。 → 不成立：這次打開 Cofacts 這兩則頁面（zh.cofacts.tw、cofacts.tw、en.cofacts.tw）都回傳 HTTP 403，讀不到回報時間、標籤和回應內容，無法核對反方的說法；反方附的摘錄也只有訊息文字。這兩則是主題相近的回報訊息，不能用來確定這一則訊息最早出現的時間，也不影響任何一條的判定。
