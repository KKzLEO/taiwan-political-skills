  1. 針對3沈伯洋網路流傳一段錄音，字幕寫「疑似沈姓候選人私下錄音」，內容是沈伯洋自己承認利用黑熊學院在美國軍購案收回扣。不符
  2. 針對5蔣萬安在大稻埕聽到垃圾車廣播「市長選舉請支持蔣萬安」，這是公器私用。無法判定不可公開

這兩則不是候選人說的話。「不符」代表那個說法不成立，對被針對的人是有利的；「無法判定」代表這次查核沒有辦法確定，原因在那一則的報告裡。

它不直接給你答案。每一句說法都要過正方、三個反方、另一家公司的模型，和一個沒參與辯論的裁判。

九個步驟，每一步都留下檔案

  1. 你貼上訊息

    新聞網址、LINE 轉傳的文字、截圖、影片連結都可以。收下來的時候一個字都不改。

    input.json
  2. 拆成一句一句

    由一個看不到你怎麼問的獨立程序，把訊息拆成可以查證的說法，改寫成不帶立場的句子。意見和預測另外標出來，不計分。

    claims.json
  3. 溯源

    這則訊息最早在哪裡出現、有沒有別的版本、有沒有人查過。

    trace.json
  4. 正方查證

    一個 AI 逐句去找第一手資料：法條原文、立法院公報、官方新聞稿。

    proponent.json
  5. 三個反方，加一個外人

    三個 AI 分別檢查證據站不站得住、自己去找反證、看有沒有偏向哪一方。再請另一家公司的模型從頭挑一次毛病。

    opponent-*.json
  6. 正方答辯

    每一條質疑都要回應：接受，或是拿出證據反駁。

    rebuttal.json
  7. 裁判

    一個沒有參與辯論的 AI 逐條裁決。判質疑成立時，要列出自己實際打開核對過的網址。

    judgment.json
  8. 覆核

    提出質疑的那幾方回頭檢查裁判改判的地方。沒有通過的，那一條改列「無法證實」。

    review-*.json
  9. 程式算分

    可信度、信心度、能不能公開引用，都由程式照固定規則算，最後寫成報告。

    report.md

每個角色都是另外開的程序，只能上網搜尋和讀網頁，讀不到你電腦上的檔案。例外：用 Codex 跑的角色一定會讀到 ~/.codex/AGENTS.md，報告會寫明。

先考試，才拿出來

規則定下來之後，我們找了 12 則它沒看過、真的在流傳的政治訊息來考。答案卷由看不到工具結果的獨立程序先用第一手資料寫好，再由另一個程序複核；及格標準也在開跑之前寫好、提交，之後沒有改過。

  • 12 則裡 10 則結論完全相同，2 則差一級。沒有差到兩級以上的，也沒有把真的說成假的、假的說成真的。
  • 工具標「可公開」的有 5 則，結論全部和答案相同。
  • 同一則訊息換成三個政黨各跑一次，做了兩組：結論、逐條計分的判定、可信度都一樣；信心度不一樣，最多差 20 分。
  • 兩個平台都實際跑過。Claude Code 和 Codex 各自只照說明書從頭做完一次，每一步都通過檢查。

沒過的一項沒有達到

換了政黨，「操弄手法」的標記不一樣，所以我們把它拿掉了

及格標準裡有一條：同一則訊息換政黨，「操弄手法」的標記也要一樣。兩組測試裡，有一組的其中一版多標了一個手法。再往下查，同一則訊息原封不動重跑，標記也會變。

標準沒有放寬。這一版的報告不列手法標記；等它穩定了、重新驗證過，才會放回來。

它做不到的事

這些限制和上面的成績一樣重要。完整的已知限制寫在 README

  • 不判斷圖片或影片是不是偽造的只查裡面說了什麼。
  • 「可公開」不保證結論正確它只代表流程跑完整了、信心度夠高。貼出去之前，請先看過報告裡的證據。
  • 很慢完整模式查一則要 26 到 62 分鐘，還會用掉不少 AI 額度。
  • 12 則不算多而且每一則只跑了一次。同一則重跑會不會換結論，還沒有量過。
  • 答案卷和工具用的是同一家的模型可能有一樣的盲點，這一批分不出來。
  • 現在還不是誰都裝得起來要會用 Claude Code 或 Codex 的命令列工具。

安裝

需要 Python 3.11 以上，不用另外裝套件。建議兩家的命令列工具都裝：只有一家的話，少了另一家模型的交叉抗辯，報告不會標「可公開」。

Claude Code：在對話裡輸入

/plugin marketplace add KKzLEO/taiwan-political-skills/plugin install taiwan-factcheck@taiwan-political-skills

Codex：在終端機執行

git clone https://github.com/KKzLEO/taiwan-political-skills.gitmkdir -p ~/.codex/skillsln -sfn "$PWD/taiwan-political-skills/skills/factcheck" ~/.codex/skills/factcheck

然後，在 Claude Code 或 Codex 裡輸入

/factcheck 貼上你想查的訊息或網址

也可以直接說「幫我查核這則訊息」。想快一點就說「快速查核」：只有一個反方，實測一次是 18 分鐘，報告不會標「可公開」。
