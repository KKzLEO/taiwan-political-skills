一則訊息，是這樣被查的

這是一個裝在 Claude Code 或 Codex 裡的查核流程。你貼上一則訊息，它不是直接給答案，而是讓幾個互相看不到對方的 AI 照下面的順序各做各的事，最後由程式照固定的規則算分。

每一步都會在你的電腦留下一個檔案，所以一份報告是怎麼得出來的，任何人都可以從頭檢查一遍。

  1. 你貼上訊息

    新聞網址、LINE 轉傳的文字、截圖、影片連結都可以。收下來的時候一個字都不改。

    input.json

  2. 拆成一句一句

    由一個看不到你怎麼問的獨立程序，把訊息拆成可以查證的說法，改寫成不帶立場的句子。意見和預測另外標出來，不計分。

    claims.json

  3. 溯源

    這則訊息最早在哪裡出現、有沒有別的版本、有沒有人查過。查核機構的結論只當線索，會回到原始資料重新驗證。

    trace.json

  4. 正方查證

    一個 AI 逐句去找第一手資料：法條原文、立法院公報、官方新聞稿。

    proponent.json

  5. 三個反方，加一個外人

    三個 AI 分別檢查證據站不站得住、自己去找反證、看有沒有偏向哪一方。再請另一家公司的模型從頭挑一次毛病。

    opponent-A.json … opponent-X1.json

  6. 正方答辯

    每一條質疑都要回應：接受，或是拿出證據反駁。

    rebuttal.json

  7. 裁判

    一個沒有參與辯論的 AI 逐條裁決。判質疑成立時，要列出自己實際打開核對過的網址。

    judgment.json

  8. 覆核

    提出質疑的那幾方回頭檢查裁判改判的地方。沒有通過的，那一條改列「無法證實」。

    review-*.json

  9. 程式算分

    可信度、信心度、能不能公開引用，都由程式照固定規則算，AI 改不了。同一份判定，每次算出來都是同樣的分數。

    verdicts.json　score.json　report.md

一次真的查核

2026 年 11 月 20 日，Claude Code 只拿到一句「幫我查核這則 LINE 轉傳的訊息」，從頭做到尾，花了 48 分鐘，中途沒有人插手。

立法院昨天三讀通過，以後騎機車一律要開大燈，沒開罰三千！快轉給家人。
錯誤正確

不符可信度 0信心度 高（100）完整模式・跨模型 1 席可公開

  • 立法院沒有三讀通過和機車開大燈有關的法案；訊息說的「昨天」那一天根本沒有開院會。
  • 現行規定只要求夜間、隧道、濃霧這些情況開頭燈，沒有「一律要開」。
  • 一般道路沒開燈的罰鍰是 1,200 到 3,600 元；三千元只出現在高速、快速公路。

6 條說法、30 筆來源、11 條質疑（8 條被裁判判成立）。

先考過，才拿出來

規則定下來之後，我們找了 12 則它沒看過、真的在流傳的政治訊息來考。答案卷由看不到工具結果的人先用第一手資料寫好；及格標準也在開跑之前寫好、提交，之後沒有改過。

  1. 美國軍購「浮編 9500 億」不符
  2. 邱鎮軍赴中「見中共政委」大致符合
  3. 黃國昌、租金補貼「砍光光」部分符合
  4. 共諜案「民主大輕判」圖卡差一級
  5. 八位大法官、修法要十人符合
  6. 海鯤艦進水、主機故障無法判定
  7. 高雄敬老卡 1/31 前過卡不符
  8. 警消退休金 80%、每年 1.25%差一級
  9. 輝達北士科「跟北市府沒關係」不符
  10. 電價喊漲（2024 年的舊聞）大致符合
  11. 運動幣登記時間（已經截止）不符
  12. 國軍加薪（公視新聞網址）符合

結論和答案卷相同差一級這是工具和答案卷的比對，不是可以拿去引用的查核報告。

  • 12 則裡 10 則結論完全相同，2 則差一級，沒有差到兩級以上的，也沒有把真的說成假的、假的說成真的。
  • 工具標「可公開」的有 5 則，結論全部和答案相同。
  • 同一則訊息換成三個政黨各跑一次，做了兩組：結論、逐條計分的判定、可信度都一樣。
  • 兩個平台都實際跑過。Claude Code 和 Codex 各自只照說明書從頭做完一次，每一步都通過檢查。

沒過的一項，我們把它拿掉了

及格標準裡有一條：同一則訊息換政黨，「操弄手法」的標記也要一樣。兩組測試裡，有一組的其中一版多標了一個手法。再往下查，同一則訊息原封不動重跑，標記也會變。

標準沒有放寬。這一版的報告不列手法標記；等它穩定了、重新驗證過，才會放回來。

它做不到的事

這些限制和上面的成績一樣重要。

  • 不判斷圖片或影片是不是偽造的，只查裡面說了什麼。
  • 「可公開」不保證結論正確。它只代表流程跑完整了、信心度夠高。貼出去之前，請先看過報告裡的證據。
  • 很慢。完整模式查一則要 26 到 62 分鐘，還會用掉不少 AI 額度。
  • 12 則不算多，而且每一則只跑了一次。同一則重跑會不會換結論，還沒有量過。
  • 答案卷和工具用的是同一家的模型，可能有一樣的盲點，這一批分不出來。
  • 現在還不是誰都裝得起來。要會用 Claude Code 或 Codex 的命令列工具。

怎麼用

需要 Python 3.11 以上，不用另外裝套件。建議兩家的命令列工具都裝：只有一家的話，少了另一家模型的交叉抗辯，報告不會標「可公開」。
