  2. 命題C2判定錯誤（覆核通過）重要性 5

    原文說法

    以後騎機車一律要開大燈

    理由

    現行規定沒有要求騎機車一律開大燈，也查不到會改成這樣的修法。道路交通安全規則第109條（本條最近一次修正是108年10月1日）規定，夜間、行經隧道與調撥車道、遇濃霧雨雪天色昏暗或視線不清時應開亮頭燈，行經公告的山區或特殊路線路段、涵洞、車行地下道則依標誌指示使用燈光；同規則第2條的汽車包括機車。全天開亮頭燈只適用大型重型機車行駛快速公路，以及550立方公分以上大型重型機車行駛高速公路（高速公路及快速公路交通管制規則第20條）。道路交通安全規則最近一次修正（115年11月6日）只改第52-1、61-1條，道路交通管理處罰條例最近一次修正（115年8月17日公布）也沒有動到燈光條文。交通部105年曾說明，白天在一般道路不開頭燈不處罰。沒有找到主管機關在2026年針對這一則訊息的說明。

    證據S1, S23, S2, S18, S5, S17, S22, S15, S21

  3. 命題C3判定錯誤（覆核通過）重要性 3

    原文說法

    沒開罰三千

    理由

    機車沒開大燈並不是一律罰三千元，也查不到把罰鍰改成三千元的修法。一般道路適用道路交通管理處罰條例第42條，不依規定使用燈光處1,200元以上3,600元以下罰鍰；115年5月法院判決引用的統一裁罰基準，機車或小型車期限內繳納或到案是1,200元，而且只處罰依規定應開燈而沒開的情形。三千元只出現在特定情形：大型重型機車行駛高速、快速公路應全天開亮頭燈，在這些道路不依規定使用燈光，依同條例第33條第1項第6款處3,000元以上6,000元以下罰鍰。訊息把三千元說成所有機車沒開大燈的罰鍰，而且說成新三讀的規定，和條文不符。警政署裁罰基準表的 PDF 這次讀不到文字，表列金額沒有直接核對，以上依據是法條本文。

    證據S3, S19, S20, S24, S22, S25, S1, S18

  4. 命題C4判定錯誤（覆核通過）重要性 3

    原文說法

    以後騎機車一律要開大燈（訊息沒有明說；這一項查的是它暗示的事，問法在辯論中修正過，見理由）

    理由

    現行有效的規定沒有「機車一律開大燈、沒開就罰」，也查不到會讓這種規定開始適用的三讀。原文寫的是「三讀通過，以後一律要」，沒有說規定已經生效，這一條照「三讀通過之後就開始適用」來判斷。道路交通安全規則第109條和道路交通管理處罰條例第42條都沒有這項內容，立法院紀錄裡也查不到機車開大燈的提案、草案或三讀。背景：依同條例第93條，施行日期由行政院以命令定之，三讀後還要總統公布、另定施行日；例如115年7月28日三讀的修正，8月17日公布，施行日期由行政院另定。

已檢驗的質疑

  • （C1）「內容與騎機車開大燈有關」把原訊息擴大成任何涉及機車頭燈的法案，連燈具設備或特定道路管制的修法也可能算進去。建議改成「立法院三讀通過一項要求騎機車一律開大燈的法案」。原文「昨天」所指的日期已由 C5 查核。 → 不成立：這一條查的是「有沒有這次三讀」，「一律要開」的內容由另一條查；把「一律」寫進來，兩條會重疊。現行寫法比原文寬，對訊息較有利，沒有加重原文的說法。即使照較寬的範圍查，立法院第11屆第6會期第7次、第8次院會的議程都沒有機車頭燈的項目，道路交通管理處罰條例最近一次三讀（115年7月28日）改的也不是燈光條文，改不改寫都不影響判定。
  • （C4）原文寫「以後」，沒有交代哪一天開始適用。C4 加入「已經生效，現在就適用」，把可能的讀者解讀寫成原訊息的主張。建議刪除這條隱含命題，由 C2 查核原文所稱將來一律開燈的義務。 → 不成立：改寫比原文強這一點是對的，已經修正成「三讀通過之後就開始適用」；但刪掉整條沒有必要。三讀、公布、施行是不同階段。訊息寫「三讀通過，以後一律要、沒開罰三千，快轉給家人」，沒有交代施行日期，會讓讀者以為三讀後就適用，適用時點需要單獨查核。
